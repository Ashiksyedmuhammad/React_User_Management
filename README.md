React User Management

A full-stack user management system built using React + TypeScript (frontend) and Node.js + Express (backend). This project demonstrates modern practices, including Redux for state management and scalable code organization with separate client/server folders.

Features
User Authentication: Login and Registration pages.

User Profile: Update and view profile (including profile picture handling).

Admin Dashboard: Manage users with add/edit/delete features.

Theme Support: Switch between light and dark themes.

State Management: Built with Redux slices for auth and UI theme handling.

Responsive UI: Built using Tailwind CSS for quick, customizable styling.

Tech Stack
Frontend: React, TypeScript, Redux Toolkit, Tailwind CSS, Vite

Backend: Node.js, Express

Other Tools: ESLint, PostCSS
